Materials and consumables are the backbone of Digimon progression. From cloning stats to transcending your partners, every upgrade requires specific items.

---

## DigiClones

DigiClones permanently increase a Digimon's stats. They are one of the most important progression items in DMW.

### Types

| Type | Use | Source |
| ---- | --- | ------ |
| **Normal DigiClone** | Clone stats on any Digimon | Dungeon drops, packages |
| **`[Savers]` DigiClone** | Clone stats on Starter Digimon only | Starter Package |

### Stat Types

| Stat | Description |
| ---- | ----------- |
| **HP** | Increases health points |
| **AT** | Increases attack damage |
| **DEF** | Increases defense |
| **CT** | Increases critical rate |
| **HT** | Increases hit rate |
| **SK** | Increases skill damage |
| **DS** | Increases digi-soul (mana) |

### How to Use

1. Open DigiClone Set boxes to obtain individual clones
2. Right-click the clone and select your Digimon
3. Each clone permanently adds that stat to your Digimon

### Tips

* Clone HP after Transcendence for maximum benefit
* Save remaining clones for later use
* `[Savers]` clones cannot be used on Journey Digimon
* Don't waste clones on temporary Digimon

## Jumping Crystals

Jumping Crystals instantly level up your Tamer or Digimon. They are essential for fast progression.

### Types

| Type | Target | Source |
| ---- | ------ | ------ |
| **Jumping Crystal `[Tamer]`** | Tamer level | Journey Package (10) |
| **Jumping Crystal `[Digimon]`** | Digimon level | Starter Package (11), Journey Package (12) |

### Usage Strategy

1. Use `[Tamer]` crystals to reach Level 70+ quickly
2. Use `[Digimon]` crystals on your Starter first
3. Use remaining crystals on Journey Digimon
4. Save some for second Starter later

### Tips

* Crystals are limited — use them wisely
* Level 70 is the minimum for most progression
* Don't waste crystals on Digimon you won't use long-term

## Data

Data items are materials used for crafting, evolution, and Transcendence.

### Types

| Type | Use | Source |
| ---- | --- | ------ |
| **Low Class Data** | Early crafting, Transcendence | Dungeon drops, packages |
| **Mid Class Data** | Mid-game crafting | Dungeon drops |
| **High Class Data** | End-game crafting | Rare dungeon drops |
| **Devil Data** | Devil-type crafting | Devil Digimon drops |
| **Character Bound Data** | Cannot be traded | Specific dungeon drops |

### Hatch Data

Hatch Data is used to hatch DigiEggs into Digimon.

| Source | Description |
| ------ | ----------- |
| DigiEggs marked `RANK 1/DATA` | Provide hatch data when returned |
| Direct drops | From certain maps |
| NPC exchanges | Trade materials for data |

### Tips

* Return DigiEggs for Data and Attribute EXP
* Save Mid/High Class Data for crafting
* Character Bound Data cannot be traded — plan accordingly
* Farm Data from appropriate level areas

## Seal Openers

Seal Openers unlock stat bonuses from Digimon Seals.

### How Seals Work

1. Digimon drop Seals as loot
2. Collect Seals by pressing **E** to view collection
3. Use Seal Openers to unlock each Seal's stat bonus
4. Seals provide permanent stat bonuses

### Seal Stats

| Stat | Priority (SK) | Priority (AA) |
| ---- | ------------- | ------------- |
| AT | ⭐⭐⭐ | ⭐⭐⭐ |
| HP | ⭐⭐⭐ | ⭐⭐⭐ |
| CT | ⭐⭐ | ⭐⭐⭐ |
| HT | ⭐⭐ | ⭐⭐⭐ |
| SK | ⭐⭐⭐ | ⭐ |
| DS | ⭐⭐ | ⭐ |

### Tips

* Aim for 500+ seals on each stat during early game
* Don't worry about Field Boss or Dungeon Boss Seals yet
* Seal stats are permanent — invest early
* Check your Seal collection regularly

## Transcendence Materials

Transcendence is a major power spike that significantly increases your Digimon's stats.

### Requirements

| Requirement | Description |
| ----------- | ----------- |
| **Digimon Level** | Must be Level 125% (125% size) |
| **Money** | Approximately 5T for first Transcendence |
| **Materials** | Transcendence Chips, Fruit of Homeostasis |
| **Raremon** | For Transcendence system unlock |

### Transcendence Chips

| Type | Use | Source |
| ---- | --- | ------ |
| **Mid Class Transcendence Chip** | Mid-game Transcendence | Starter Package (2), dungeon drops |
| **Transcendence Chip Exchange Ticket** | Exchange for chips | Dungeon rewards, Gizumon Lab |

### Fruit of Homeostasis `[Savers]`

Used to increase Starter Digimon to 125% size, enabling Transcendence.

* Starter Package (500)
* Area Completion rewards
* Event drops

### Growth Fruit `[Savers]`

Similar to Fruit of Homeostasis — increases Starter to 125%.

* Starter Package (1)
* Journey Gift Package
* Area Completion rewards

### Raremon

Two Level 5 Raremon DigiEggs are included in the Starter Package.

* Hatch with 30 Low Class Devil Data
* Use for Transcendence system unlock
* Don't hatch until you have enough materials

### Accessory Tiers

| Tier | Duration | Source |
| ---- | -------- | ------ |
| **Saber-Toothed** | Temporary | Tutorial (discard after) |
| **Novice** | Permanent | Novice Accessory Box |
| **Underworld** | 30 days | Underworld Accessory Box |
| **Radiant Holy Beast** | Permanent | Dungeon farming |
| **Royal** | Permanent | End-game raids |

### Accessory Slots

| Slot | Priority |
| ---- | -------- |
| Ring | ⭐⭐⭐ |
| Necklace | ⭐⭐⭐ |
| Earrings | ⭐⭐ |
| Bracelet | ⭐⭐ |

### Tips

* Don't open Underworld Box until ready to use
* Discard Saber-Toothed accessories — they're weak
* Focus on completing sets before upgrading
* Don't invest heavily in temporary accessories

## Consumables

Consumables provide temporary buffs and effects for dungeon runs and combat.

### Buff Items

| Item | Effect | Duration |
| ---- | ------ | -------- |
| **1-Hour Buff** | Various stat boosts | 1 hour |
| **2-Hour Buff** | Various stat boosts | 2 hours |
| **Amplification Booster +1000%** | +1000% EXP from kills | 31 minutes |
| **1-Day DigiAura** | Reduces DS costs | 1 day |
| **1-Day Sneakers** | Increases movement speed | 1 day |
| **1-Day DATS Uniform** | Stat boosts | 1 day |

### Expansion Items

| Item | Effect |
| ---- | ------ |
| **Inventory Expansion** | Increases inventory slots |
| **Warehouse Expansion** | Increases warehouse slots |
| **Digimon Archive Expansion** | Increases Digimon storage |
| **Expansion Package** | Contains multiple expansions |

### Tips

* Save buffs for dungeon runs — don't waste on questing
* Use movement speed items early for faster questing
* Expansion items are valuable — don't use prematurely
* Amplification Boosters don't increase quest EXP

## Digivice Items

The Digivice is your primary equipment piece that provides core stats and abilities.

### DMW Digivice

* Obtained from Journey Package
* Unlocked and equipped immediately
* Can be enhanced later
* Essential for all content

### Digivice Enhancement

| Level | Requirement |
| ----- | ----------- |
| Lv.1 | Default |
| Lv.2+ | Enhancement materials from dungeons |

### Tips

* Equip Digivice immediately
* Don't worry about enhancement early
* Focus on other gear first
* Enhancement becomes important in mid-game
