## Overview

**Rank: SSS** — Ogudomon is the **Super Great Demon Lord**, an aggregation of
all seven **Seven Demon Lords'** souls. Similar to **Apocalymon (Psychic)** in
scope, it requires extra material work. Like Apocalymon, the seven source
Digimon are the **NORMAL** (non-jogress) versions — sacrifice a *separate*
Lucemon if you want to keep your Lucemon Satan Mode.

> 📍 Start at the **White-bearded Guru — Extraordinary Evolution** at **DATS Center**.


## Requirements 📋

- Lv. 70+ Tamer
- Lv. 120+ on **all seven** of the following base Digimon (must be the *normal* version):
  - **Lucemon**
  - **Tsukaimon** (Barbamon line)
  - **Tsukaimon** (Daemon line)
  - **Syakamon**
  - **Psychemon**
  - **Impmon**
  - **Salamon** (Lilithmon line)
- 4× **500 Currency Mega** (4× Tera total)
- 7× **The Source of Sin** (must be the **non-tradable** kind — see Notes)
- Completion of each Demon Lord's own questline if you didn't pay for the item

## The Seven Sacrifices 🩸

Sacrifice each of the seven base Digimon to obtain a **Source of Sin** and a
**Data Code** for its corresponding Demon Lord. You can skip the per-Demon-Lord
questline by buying the **Source of Sin** from the **Cash Shop** (tradeable),
but you still need the **non-tradable** version — see Notes.

| Base Digimon | Demon Lord | Code Obtained |
| --- | --- | --- |
| **Lucemon** | Lucemon Falldown Mode | Data Code of Lucemon Falldown Mode |
| **Tsukaimon** (Barbamon line) | Barbamon | Data Code of Barbamon |
| **Tsukaimon** (Daemon line) | Demon | Data Code of Demon |
| **Syakamon** | Leviamon | Data Code of Leviamon |
| **Psychemon** | Belphemon | Data Code of Belphemon |
| **Impmon** | Beelzebumon | Data Code of Beelzebumon |
| **Salamon** (Lilithmon line) | Lilithmon | Data Code of Lilithmon |

**✅ All Seven Sources of Sin Acquired**


## How to Start a Demon Lord's Quest

1. Bring the **Rookie/Base Form** of your chosen Digimon (must be **Lv. 120**)
   to the **White-bearded Guru** at **DATS Center**.
2. The Guru triggers a quest unique to that Digimon — there are **7 different
   questlines** in total (one per Demon Lord).


## Per-Demon-Lord Questlines ⚔️

Each row = the boss kills you must complete to clear that Demon Lord's
questline. Any Digimon can be used to defeat the enemies.

| Source of Sin | Required Kills |

| **Belphemon** | 7× **Omegamon Zwart** in **Royal Knights Dominion** + 7× **Alphamon Ouryuken** in **Royal Knights Dominion** |
| **Beelzebumon** | 7× **Qinglongmon** in **Descending Thunder God (Hard Mode)** |
| **Lilithmon** | 7× **Dexmon** in **Royal Base (Easy)** |
| **Barbamon** | 7× **Xuanwumon** in **Scar of Water Crystal (Hard Mode)** |
| **Leviamon** | 7× **Baihumon** in **Trace of Black Steel (Hard Mode)** |
| **Demon** | 7× **Zhuqiaomon** in **Uprising Flame (Hard Mode)** |
| **Lucemon** | 7× **Dexmon** in **Digimon Arena** on **Round 35** |

**✅ All Seven Demon Lord Quests Complete**

## Important 💡

- The seven source Digimon must be the **NORMAL** versions — keep a *separate*
  Lucemon if you want to keep Lucemon Satan Mode in your roster.
- The **Source of Sin** from the Cash Shop is **tradeable**, but you must
  use the **non-tradable** kind when sacrificing the Digimon for Ogudomon.
  To convert it, talk to **Digitamamon (Item Make)** at DATS Center, then
  **Extra Evolution → Source of Sin**.
- You can insert any string (e.g. `"[email protected]"`) as a placeholder
  email during the sacrifice prompts.
- Use any Digimon to defeat the enemies required for the per-Demon-Lord
  quests — the kills do not need to come from a specific Digimon.


## Result ✅

**7× Sacrifices + 7× Per-Lord Quests + Ogudomon Questline** → ➡️ 😈 **Ogudomon Unlocked**
