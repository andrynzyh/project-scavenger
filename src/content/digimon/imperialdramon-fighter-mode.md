## Overview

**Rank: SSS** — Imperialdramon Fighter Mode is the upgraded form of
**Imperialdramon Dragon Mode** (Wormmon + Veemon sides).

## Requirements 📋

- Lv. 70+ Tamer
- Lv. 60+ Wormmon (Imperialdramon Dragon Mode unlocked)
- Lv. 60+ Veemon (Imperialdramon Dragon Mode unlocked)

> 📍 Pick up the quest from **Calumon** at **DATS Center**.

## Wormmon Branch 🐛

1. Go to **Calumon** in DATS Center and begin the Fighter Mode questline.
2. Travel to **Oil Refinery-2** and defeat the required **Mammothmon**.
3. Continue with **Richard Sampson**.
4. Travel to **Oil Refinery-1** and defeat the required **SkullSatamon**.
5. Return to Richard Sampson.

**✅ Wormmon Side Complete**

## Veemon Branch 💎

1. Begin the Veemon branch through **Calumon**.
2. Travel to **Oil Refinery-3** and defeat the required **Knightmon**.
3. Continue with **Richard Sampson**.
4. Travel to **Yokohama Village** and defeat the required **SkullSatamon**.
5. Return to Richard Sampson.

**✅ Veemon Side Complete**

## Unlock 🔓

Complete both partner branches and **Imperialdramon Fighter Mode** becomes
available.

## Important 💡

- Tamer **Lv. 70+** required.
- Both partners must be **Lv. 60+**.
- **Imperialdramon Dragon Mode** must already be unlocked.
- Any Digimon can generally be used to defeat the quest monsters.
- If the **SkullSatamon** quest doesn't register correctly, **switching channels**
  can resolve the issue.

## Result ✅

**Imperialdramon Dragon Mode** → ➡️ ⚔️ **Imperialdramon Fighter Mode Unlocked**

# Imperialdramon Fighter Mode (Tempered)

## Rank

**SSS**

## Requirements


- Lv70+ Tamer
- Lv60+ Wormmon
- Lv60+ Veemon
- Imperialdramon Dragon Mode progression


## Unlock Guide


The Tempered Fighter Mode progression requires the Dragon Mode
line to be completed first.

### Wormmon

1. Complete the Calumon progression.
2. Defeat Mammothmon in Oil Refinery 2.
3. Return to Calumon.
4. Continue the Richard progression.
5. Defeat SkullSatamon in Oil Refinery 1.
6. Return to Richard.

### Veemon

1. Complete the Calumon progression.
2. Defeat Knightmon in Oil Refinery 3.
3. Return to Calumon.
4. Continue the Richard progression.
5. Defeat SkullSatamon in Yokohama Village.
6. Return to Richard.



## Notes


If the SkullSatamon quest does not register, changing channels
can resolve the issue.
